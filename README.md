# Parking Lot Automation System

A Java-based Parking Lot Automation System that manages vehicles, parking spots, floors, parking tickets, pricing, and payments.

## Features

* Bike, Car and Truck parking
* Automatic parking spot allocation
* Parking ticket generation
* Normal and weekend pricing
* UPI, Card and Cash payment support
* Parking availability display

## Design Patterns

* **Factory Pattern** – Vehicle creation
* **Observer Pattern** – Parking availability updates
* **Strategy Pattern** – Parking, pricing and payment strategies
* **Singleton Pattern** – Parking Lot management

## Technologies

* Java
* OOP
* Design Patterns

## Run

```bash
javac ParkingLot.java
java program1008
```
